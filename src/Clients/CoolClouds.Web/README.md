# CoolClouds.Web

Blazor WebAssembly app. Generated by `scripts/scaffold` (`dotnet new blazorwasm`).

Shares `Contracts`, `ApiClient` and `Rendering` with the mobile app. Freehand drawing works best here
(mouse, trackpad, stylus).

Note: link previews on X/Facebook/Pinterest don't run JavaScript, so share links point to the
server-rendered page in the API (`/c/{slug}`), not to this app.
