# CoolClouds.Mobile

.NET MAUI app for iOS and Android (plus a Windows target for quick testing without a Mac).
Generated by `scripts/scaffold` (`dotnet new maui`).

Suggested layout:

| Folder | Contents |
| --- | --- |
| `Pages/` | Capture, Editor, MyCreations, Feed, CreationDetail, Profile |
| `ViewModels/` | One per page (CommunityToolkit.Mvvm) |
| `Editor/` | SkiaSharp canvas view, guided tap-to-place, freehand strokes, undo/redo |
| `Services/` | Auth (Entra External ID), camera/photo picker, share sheet |

API base address while developing:
- Android emulator: `http://10.0.2.2:<api port>`
- Real phone: your Dev Tunnel HTTPS URL
