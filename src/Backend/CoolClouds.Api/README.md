# CoolClouds.Api

ASP.NET Core Web API, hosted on Azure App Service. Generated by `scripts/scaffold` (`dotnet new webapi`).

Suggested layout (one folder per feature, minimal API endpoints):

| Folder | Endpoints (see `ApiRoutes` in Contracts) |
| --- | --- |
| `Features/Users/` | `GET /api/v1/me` |
| `Features/Photos/` | `POST /api/v1/photos/uploads` — issues a short-lived SAS upload URL |
| `Features/Creations/` | save, list, `PUT .../visibility`, `POST .../reports` |
| `Features/Feed/` | `GET /api/v1/feed?sort=newest|top` — only `CanBeSeenByOthers` creations |
| `Features/Ratings/` | `POST .../ratings` — updates the cached average on `Creation` |
| `Features/Subscriptions/` | RevenueCat / Stripe webhook → `User.SubscriptionStatus` |
| `Features/Share/` | `GET /c/{slug}` — server-rendered HTML with `og:image` / `twitter:card` tags |

Auth: JWT bearer tokens from Microsoft Entra External ID (Google, Apple, Facebook, email).
