# CoolClouds.Functions

Azure Functions (.NET isolated worker). Generated by `scripts/scaffold` (`func init`).

| Function | Trigger | Does |
| --- | --- | --- |
| `ProcessUploadedPhoto` | Blob `originals/{name}` | Thumbnail → Content Safety → update `CloudPhoto.ModerationStatus` |
| `ModerateCreation` | Blob `creations/{name}` | Content Safety on the composited image → `ModerationResult` rows |
| `SendNotification` | Service Bus queue `notifications` | Push via Azure Notification Hubs (ratings, moderation outcome) |

Moderation is non-bypassable: nothing becomes visible to others until these functions mark it `Clear`.
