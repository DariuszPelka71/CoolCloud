# Aspire (local orchestration)

- `CoolClouds.AppHost` — run this to start the whole backend locally:
  `dotnet run --project src/Aspire/CoolClouds.AppHost`
  It starts SQL Server and Azurite in Docker, the API and the Functions, and opens the dashboard.
- `CoolClouds.ServiceDefaults` — OpenTelemetry, health checks and HTTP resilience,
  referenced by the API and Functions (`builder.AddServiceDefaults()`).

Both projects are generated by `scripts/scaffold`, which also writes the wiring in `AppHost.cs`.
